天玄以北斗为纲、二十八宿为目。此块给出完整对照，供你按宿检索构件与指标。

## 用法

- 提到构件时带上宿名，便于在诊断面板（星图）中定位指标。
- 讨论运行环境问题时优先看**玄武七宿**；讨论工具与外境看**白虎七宿**。
- 距度合计 365¼ 度（东方 75 + 北方 98 + 西方 80 + 南方 112 = 365，箕宿带四分之一）。
